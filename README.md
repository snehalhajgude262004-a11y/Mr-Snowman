 Mr. Snowman – Ice Cream Parlour Website
Mr. Snowman is a web-based ice cream parlour application built using Java web technologies. It provides a user-friendly interface for customers and an admin login area.


 Features
Customer login and registration
Admin login
Ice cream parlour website interface
Java-based server-side functionality
Database integration using MySQL
JSP and Servlet-based web application

Technologies Used
Java
JSP and Servlets
Maven
Apache Tomcat 9
Hibernate
MySQL
 HTML, CSS, JavaScript, and Bootstrap (where used in the project)

Local Setup
Install JDK, Maven, Apache Tomcat 9, and MySQL.
Import the project into Eclipse as an existing Maven project.
Create and configure the required MySQL database.
Configure database credentials locally in `src/main/resources/META-INF/persistence.xml`.
Build the project as a WAR and run it on Tomcat.

Important Security NoteThe database credentials in this public repository are placeholders. Configure your own credentials locally before running the application. Never commit real passwords or private credentials.


Project Purpose
This project demonstrates Java web development, authentication workflows, database integration, and deployment using Apache Tomcat.
